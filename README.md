# pSWG

[View dev details and notes here](https://pstraw.net/notes/pswg-feature-tracking/). Sit back, relax, and enjoy the ride in this star wars galaxy.

This is a fork of [SWGEmu Core3](https://github.com/swgemu/Core3) with the goal of keeping up-to-date with JTL development. It has various QOL additions & fixes from popular (public) SWGEmu servers copy/pasted in - thanks to all of the people who have created some sweet servers over the years. If you'd like specific credit for code you wrote, please open a PR and I'll include it below.

Code included from:

- [SWGEmu Core3](https://github.com/swgemu/Core3)
- [SWG Infinity](https://github.com/swginfinity/public)
- [SWG SR2](https://github.com/swgsremu/sentinelsrepublic-server)
- [SWG Aftermath](https://github.com/SWGAftermath/Aftermath)
- [SWG Flurry](https://github.com/Thrax989/SWGFlurry)
- [Tarkin's Revenge](https://bitbucket.org/tarkinsrevenge/tarkins-revenge/src/master/)
- [MTG (Mod The Galaxy)](https://modthegalaxy.com/)
