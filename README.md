# pSWG

## Discontinued
After about a month of working on this project, I've decided to discontinue it. The decision to work with the latest SWGEmu/Core3 code was inspired by trying to learn more about the popular server at the time (SR2) which decided to stay in sync with upstream Core3 in order to enable JTL. While the SWGEmu/Core3 project is great and the code is very stable, it's just not very fun to play on. There are so many quality-of-life changes that need to be put into place, and the major ones (ie. 2024 loot rework) require cpp knowledge that I don't have right now. The best popular server references are using older versions of Core3 code, and have been stable for a long time now. If I decide to try again with a SWG server, that's where I'm going to start rather than  Core3 vanilla. It's been fun, and I've learned a lot! As of 07/04/2025 the pSWG `dev` branch is working just fine and can be used as a starting point for anybody who wants to go down this path and continue to merge in the latest Core3 upstream changes. There's also an electron launcher if you're into that sort of thing. Good luck!

## Details
[View dev details and notes here](https://pstraw.net/notes/pswg-dev-tracking/). Sit back, relax, and enjoy the ride in this star wars galaxy.

This is a fork of [SWGEmu Core3](https://github.com/swgemu/Core3) with the goal of keeping up-to-date with JTL development. It has various QOL additions & fixes from popular (public) SWGEmu servers copy/pasted in - thanks to all of the people who have created some sweet servers over the years. If you'd like specific credit for code you wrote, please open a PR and I'll include it below.

Code included from:
