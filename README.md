# pSWG

Sit back, relax, and enjoy your visit to this star wars galaxy.

## No Longer Maintained

As of late July 2025 I've decided to stop working on this project. It was fun to implement popular servers' code changes into the latest swgemu code with the help of AI. After a while, I just lost steam and wanted to move on to other projects. Maybe one day I'll pick it back up ;]

## Details

This is a fork of [SWGEmu Core3](https://github.com/swgemu/Core3) which is kept up-to-date for JTL. It has various QOL additions & fixes from popular public SWGEmu servers pasted in. If you'd like specific credit for code you wrote, please open a PR and I'll include it below. [View code change details and notes here](https://pstraw.net/notes/pswg-dev-tracking/).

Code included from:

- [SWGEmu Core3](https://github.com/swgemu/Core3)
- [SWG Infinity](https://github.com/swginfinity/public)
- [SWG SR2](https://github.com/swgsremu/sentinelsrepublic-server)
- [SWG Aftermath](https://github.com/SWGAftermath/Aftermath)
- [SWG Flurry](https://github.com/Thrax989/SWGFlurry)
- [Tarkin's Revenge](https://bitbucket.org/tarkinsrevenge/tarkins-revenge/src/master/)
